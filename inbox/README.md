# 待发布 TXT 文件夹

把已经写好的 TXT 文件上传到这个文件夹，文件名会作为文章标题。

操作步骤：

1. 打开 GitHub 仓库。
2. 进入 `inbox` 文件夹。
3. 点击 `Add file` → `Upload files`。
4. 上传 `.txt` 文件。
5. 点击 `Commit changes`。

系统会自动把 TXT 转换成博客文章，并删除这里的原 TXT 文件。

## 自动分章

如果 TXT 中至少有两个章节标题，系统会自动拆分为多篇文章，并创建连载目录。

支持的主要标题格式：

- `第一章 标题`
- `第1章 标题`
- `序章`
- `楔子`
- `终章`
- `番外`
- `Chapter 1`

文件名会作为连载书名。
