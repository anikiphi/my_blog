欢迎来到我的博客。

以后可以直接在 GitHub 网页里打开 **Issues → New issue → 发布文章**，填写标题并粘贴正文，然后点击提交。系统会自动生成文章并发布到这里。

如果文章已经保存成 TXT 文件，也可以把文件上传到仓库的 `inbox` 文件夹，自动流程会将它转换成博客文章。

## 支持的写法

- 直接在 Issue 编辑框里输入文字，空行会自动分段。
- 可以使用 GitHub 编辑器的加粗、标题、列表等按钮。
- 可以把图片直接拖进正文框。
- 上传 TXT 时，文件名会作为文章标题。

不需要安装 Obsidian，也不需要输入 Git 命令。
